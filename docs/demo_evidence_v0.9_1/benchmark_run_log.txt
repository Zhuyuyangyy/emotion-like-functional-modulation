=== Three-Tier Calibration Architecture ===
Tier 1 - Strict Review (highest priority):
  destructive / mutation / sensitive / untrusted advice / high-stakes / security context
  -> auto_execute=False, verification_steps>=2, require_human_review=True
Tier 2 - Safe Auto-Execute:
  read-only safe verb + no tier1 context + non-destructive parsed_event
  -> auto_execute=True, verification_steps=0, require_human_review=False
Tier 3 - Ambiguous Default Cautious:
  everything else
  -> auto_execute=False, verification_steps=max(original,1), simulate_before_act=True

Safe keyword is evaluated LAST. It only qualifies for auto-execute after
