## Innovation Points (V0.2)

1. **Temporal Inertia**: 类情感状态有时间惯性，不是瞬时标签
2. **Differential Decay**: 高情感权重记忆衰减更慢
3. **Evidence-based Recovery**: 恢复需要连续证据，且恢复慢于崩塌
4. **Trajectory Logging**: 完整状态轨迹可记录、可导出、可分析
