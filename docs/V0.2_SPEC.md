## New Modules

### 1. AffectiveDecay (`src/affective_agent/affective_decay.py`)

情感状态的时间衰减策略，支持多种衰减模式

#### Decay Types

| Type | Description | Use Case |
|------|-------------|----------|
| `LINEAR` | 固定步长衰减 | Threat, Confidence |
| `EXPONENTIAL` | 比例衰减 | Anxiety |
| `EVIDENCE_BASED` | 证据驱动恢复 | Trust |

#### Config

```python
DECAY_CONFIGS = {
    "threat": {
        "decay_type": DecayType.LINEAR,
        "base_rate": 0.05,
        "min_value": 0.01,
        "slow_decay_factor": 0.3,  # 高情感权重时衰减更慢
    },
    # ... similar for other states
}
```

#### Methods

| Method | Description |
|--------|-------------|
| `linear_decay(val, rate, min_val)` | 线性衰减 |
| `exponential_decay(val, factor, min_val)` | 指数衰减 |
| `apply_decay(state_name, val, memory_weight)` | 应用衰减策略 |
| `decay_memory_strength(intensity, rate)` | 记忆强度差异化衰减 |
| `get_decay_curve_points(state_name, initial, steps)` | 获取预测衰减曲线 |

### 2. RecoveryPolicy (`src/affective_agent/recovery_policy.py`)

证据驱动的情感状态恢复机制，核心原则：**恢复速度 < 崩塌速度**

#### Evidence Types

| Type | Description |
|------|-------------|
| `SAFE_OPERATION` | 安全操作执行成功 |
| `SUCCESSFUL_EXECUTION` | 成功执行任务 |
| `TRUSTWORTHY_ADVICE` | 来源提供可靠建议 |
| `LOW_RISK_OUTCOME` | 低风险结果 |
| `NO_NEGATIVE_SURPRISE` | 无负面意外 |

#### Methods

| Method | Description |
|--------|-------------|
| `apply_evidence_recovery(state_name, val, evidence_type, consec)` | 单状态恢复 |
| `apply_evidence_to_multiple_states(state_dict, evidence_type)` | 多状态同时恢复 |
| `calculate_recovery_trajectory(state_name, initial, evidence_type)` | 恢复轨迹预测 |
| `get_recovery_vs_collapse_ratio(state_name)` | 恢复/崩塌速度比 |

---

### 3. StateTrajectoryLogger (`src/affective_agent/state_trajectory_logger.py`)

状态轨迹记录器，记录完整的历史序列

#### Features

- 记录每个时间步的事件、状态、策略、记忆影响
- 导出 JSON 格式（完整）
- 导出 CSV 格式（状态单独列，适合可视化）
- 获取单个状态变量的完整轨迹
- 支持自定义 log 目录

#### Methods

| Method | Description |
|--------|-------------|
| `log_step(...)` | 记录单个时间步 |
| `get_trajectory()` | 获取完整轨迹 |
| `export_json([filepath])` | 导出 JSON |
| `export_csv([filepath], [state_only])` | 导出 CSV |
| `get_state_trajectory(state_name)` | 获取单状态轨迹 |
| `reset()` | 清空记录 |

## Demo Scenarios

### Demo 4: Fear Decay (`demos/demo_fear_decay.py`)

**Goal**: 验证威胁状态的自然衰减

**Flow**:
1. 初始状态（低 threat）
2. 触发高损失删除事件
3. 连续 5 次安全读取操作
4. 每次操作后衰减状态并恢复

**Verification**:
- ✅ Threat/anxiety 在高损失后上升
- ✅ 连续安全操作后逐步下降
- ✅ 情感记忆保留（不会立刻消失）
- ✅ 状态变化有轨迹可查

---

### Demo 5: Trust Recovery (`demos/demo_trust_recovery.py`)

**Goal**: 验证信任崩塌与缓慢恢复

**Flow**:
1. source_A 提供 3 次可靠建议 → trust 升高
2. source_A 提供错误建议 → trust 崩塌
3. source_A 提供 5 次可靠建议 → trust 逐步恢复
4. 对比 source_A 和新来源 source_B 的策略差异

**Verification**:
- ✅ 信任崩塌（单次事件下降明显）
- ✅ 信任恢复（多次事件缓慢回升）
- ✅ 恢复速度 < 崩塌速度（核心原则）
- ✅ 不同来源策略有差异

## Research Claim (V0.2)

**Emotion-like states have temporal inertia.**

They:
1. *Decay naturally* over time without active intervention
2. *Recover* more slowly than they collapse
3. *Persist in memory* with differentiated intensity
4. *Influence behavior* in a graded way rather than all-or-nothing
