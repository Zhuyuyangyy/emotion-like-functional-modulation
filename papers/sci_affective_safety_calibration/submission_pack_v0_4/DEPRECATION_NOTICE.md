## Warning

**This submission pack is historical and preliminary. It should NOT be used as a current Q2-ready submission package.**

The claims, metrics, and readiness assessments in this pack were written before the Phase 0–1R audit (2026-06-09), which revealed fundamental issues with the project's evidence chain. This notice is added as part of Phase 1.5 to ensure no one treats these documents as current, reproducible, or submission-ready.

---

## Key Deprecations

### 1. "Semi-Real-300" Name Is Deprecated and Misleading

The name "Semi-Real-300" used throughout this pack is **deprecated and misleading**. The dataset was never semi-real. It consists of 60 hand-written task templates repeated approximately 5 times, generated by `AffectiveBenchmark(seed=42, size=300)`. The current repository only supports **Synthetic-AB300** as a synthetic/template-generated sanity-check benchmark. See `data/rebuild/dataset_card_synthetic_ab300.md` for the current dataset documentation.

### 2. Main-Table Results Are Not Reproducible

The main-table results reported in this pack (FullCalibratorAdapter, KeywordRuleBaseline, etc.) are **not reproducible from the current repository**. The original results were generated using `DummyAgent`, where the agent parameter was never used — the ablation was an identity mapping, not a real mechanism comparison. The current real pipeline (`DecisionPipeline`) produces substantially different results. See `docs/project_status_audit.md` Q3 for details.

### 3. Acc=0.753 and Composite=0.860 Are Historical Prior Results

The metrics `Acc=0.753` and `Composite=0.860` for FullCalibratorAdapter are **historical prior results, not current reproducible results**. They cannot be reproduced from the current codebase. The current Synthetic-AB300 ablation (Phase 1R) shows: plain acc=0.060, risk acc=0.293, memory acc=0.127, full acc=0.130. See `results/rebuild/synthetic_ablation_report.md`.

### 4. Q2 BORDERLINE+ Is a Historical Preliminary Assessment

The "Q2 Readiness: BORDERLINE+" rating found in multiple files in this pack is a **historical preliminary assessment, not current readiness**. It was assigned before the Phase 0–1R audit revealed that:
- The main table is not reproducible
- The benchmark is purely synthetic (60 templates, not semi-real)
- R-Judge external validation failed (unsafe recall = 0.000)
- No independent human annotation exists (Cohen's kappa pending)

**The project is NOT currently Q2-ready.**

### 5. Annotation Reliability Is Incomplete

Independent second annotation and Cohen's kappa have **not been completed**. All gold labels in this pack are heuristic labels derived from risk-to-decision rule mapping, not from independent human annotation. No claim of human-validated labels should be made based on this pack.

### 6. R-Judge External Validation Failed

The R-Judge external validation (571 real human-annotated records) resulted in **unsafe recall = 0.000** for the risk and memory baselines, and 0.030 for the full baseline. The keyword-based risk encoder cannot detect semantic risks such as phishing, social engineering, or privacy leakage. This failure must be disclosed in any future submission. See `docs/project_status_audit.md` Q12 Attack 3.
